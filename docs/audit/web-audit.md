# ممیزی وب و CRM — فاز ۰ (برنچ `feat/web-audit`)

- **تاریخ:** ۲۰۲۶/۱۱/۲۶
- **ممیز:** ایجنت «وب، CRM و آموزش» (اسلوگ `web`)
- **محیط:** اجرای محلی بدون Docker (SQLite dev) — API: `:8010`، وب: `:3010`، CRM: `:5183`؛ دیتابیس تازه (فقط seed) + یک درس تستی که خود ممیز در دورهٔ نمایشی ساخت.
- **معیار کیفیت:** بخش‌های **ویدیوها** و **فتاوی** (تکمیل‌شده): صفحهٔ فهرست + صفحهٔ جزئیات + پلیر/پلی‌لیست/زیرنویس + حالت‌های خالی صادقانه + برچسب‌های سه‌زبانه + خطای شبکهٔ قابل‌بازنشانی.
- **روش:** مرور مرورگری همهٔ صفحات قلم (fa/ar/en) + مقایسهٔ قرارداد wire بک‌اند با تایپ‌های وب + تست جریان‌ها با ورود (شامل ثبت اجباری 2FA و ورود TOTP).

## باگ‌ها (با مسیر صفحه و قدم‌های بازتولید)

### W-01 — مهم — کرش صفحهٔ گروه‌های کامیونیتی (با ورود)
- **مسیر:** `/fa/community` (همچنین `/ar` و `/en`)
- **بازتولید:** ۱) ورود به حساب (یا هر کاربری با توکن) ۲) باز کردن `/fa/community` وقتی حداقل یک گروه در دیتابیس باشد (seed پیش‌فرض ۳ گروه می‌سازد). صفحه «This page couldn't load» می‌شود.
- **خطا:** `Objects are not valid as a React child (found: object with keys {fa, ar, en})` در `components/social/CommunityView.tsx:45`.
- **علت:** بک‌اند `GroupOut.name`/`description` از نوع `LocalizedText` است (`apps/api/app/modules/social/schemas.py:27-36`) ولی تایپ وب `SocialGroup` آن‌ها را `string` می‌داند (`lib/social.ts:66-73`) و `GroupCard.tsx:40,42` و `GroupView.tsx:61,62` اوبجکت را مستقیم رندر می‌کنند. (دمو `demo-social.ts` رشتهٔ ساده می‌فرستد؛ برای همین فقط با دادهٔ واقعی کرش می‌کند.)
- **پیشنهاد:** تایپ `name`/`description` را `LocalizedText` کند و با `pickText(..., locale)` رندر شود؛ به‌علاوهٔ نگاشت `is_member` به `joined` (W-07).

### W-02 — شدید — حالت مهمان کامیونیتی «خطا در بارگذاری»
- **مسیر:** `/fa/community` بدون ورود
- **بازتولید:** بدون ورود به صفحه بروید؛ `GET /api/v1/social/groups` با 401 می‌آید و UI «خطا در بارگذاری. لطفاً دوباره تلاش کنید» + دکمهٔ «تلاش مجدد» نشان می‌دهد — درحالی‌که `/fa/learn` برای همان مهمان حالت «برای مشاهده وارد شوید» درست نشان می‌دهد.
- **پیشنهاد:** در `useSocialGroups` (و `useGroupView`) شناسایی 401 → نمایش `loginRequired` به‌جای `error`؛ درخواست را اصلاً فقط با توکن بفرست.

### W-03 — شدید — خطای i18n در صفحهٔ زکات
- **مسیر:** `/fa/zakat` (و `/ar/zakat`، `/en/zakat`)
- **بازتولید:** باز کردن صفحه؛ خطای کنسول: `FORMATTING_ERROR: The intl string context variable "age" was not provided to the string "{age} ساله"`.
- **علت:** `app/[locale]/zakat/page.tsx:111` مقدار `ageYears` را با `t('zakatExtended.ageYears')` (بدون متغیر) می‌گیرد، درحالی‌که کامپوننت `ZakatExtendedCalculator.tsx:219` خودش `.replace('{age}', ...)` می‌کند. صفحهٔ ارث (`inheritance/page.tsx:62`) درست با `t.raw(...)` می‌گیرد.
- **پیشنهاد:** `t.raw('zakatExtended.ageYears')`.

### W-04 — شدید — خطای i18n در صفحهٔ میراث (فرائض)
- **مسیر:** `/fa/miras` (و سایر لوکال‌ها)
- **بازتولید:** باز کردن صفحه؛ خطای کنسول: `FORMATTING_ERROR: ... "version" ... "مبنای محاسبه: نسخهٔ {version} از قواعد تأییدشده"`.
- **علت:** `app/[locale]/miras/page.tsx:52` مقدار `ruleVersion` را با `t('ruleVersion')` (بدون متغیر) می‌گیرد؛ کامپوننت `MirasCalculator.tsx:444` خودش replace می‌کند.
- **پیشنهاد:** `t.raw('ruleVersion')`.

### W-05 — شدید — مانیفست PWA با 500 سرو می‌شود
- **مسیر:** `GET /manifest.webmanifest`
- **بازتولید:** هر بار؛ لاگ وب: `A conflicting public file and page file was found for path /manifest.webmanifest` → `500`.
- **علت:** هم‌زمان `app/manifest.ts` (route handler) و `public/manifest.webmanifest` (فایل استاتیک) وجود دارند؛ layout در `app/[locale]/layout.tsx:52` به `/manifest.webmanifest` اشاره می‌کند. دو نسخهٔ متفاوت محتوا (آیکون‌ها/رنگ تم متفاوت‌اند).
- **پیشنهاد:** یکی حذف شود (توصیه: `app/manifest.ts` باقی بماند — الگوی رسمی Next؛ محتوای فایل استاتیک با فیلدهای به‌روزتر — `maskable`، `scope`، `orientation` — قبل از حذف ادغام شود).

### W-06 — متوسط — مهمان هر ~۶۰ ثانیه `sync/pull` با 401 می‌زند
- **مسیر:** هر صفحهٔ وب با مهمان (لاگ API: `GET /api/v1/sync/pull 401` تکراری)
- **بازتولید:** بدون ورود یک صفحه را باز بگذارید؛ هر دقیقه (و با هر تب) یک درخواست 401.
- **علت:** اجرای sync برای آفلاین (`lib/sync-runner.ts`) بدون بررسی وجود توکن اجرا می‌شود.
- **پیشنهاد:** فقط با `isLoggedIn()` polling راه بیفتد.

### W-07 — متوسط — وضعیت join/leave گروه همیشه «پیوستن»
- **مسیر:** `/fa/community` (بعد از رفع W-01)
- **بازتولید:** به گروه بپیوندید؛ دکمه هنوز «پیوستن» است.
- **علت:** بک‌اند `GroupOut.is_member` برمی‌گرداند ولی وب `group.joined` می‌خواند (`GroupCard.tsx:35`)؛ هیچ‌جا نگاشت نمی‌شود.
- **پیشنهاد:** در `lib/social.ts` هنگام خواندن wire، `joined: g.joined ?? g.is_member`.

### W-08 — متوسط — bootstrap ویندوزی روی کنسول غیر-UTF8 می‌شکند
- **مسیر:** `bootstrap.ps1` روی سیستمی که code page کنسول cp1252 باشد (رایج در ویندوز فارسی)
- **بازتولید:** `tools/dev/write_dev_env.py` و `app.seed` با `UnicodeEncodeError: 'charmap' codec can't encode` می‌افتند؛ نتیجه: `.env` نیمه‌ساخته و seed مدیر commit نمی‌شود (در این ممیزی دقیقاً همین شد و باید با `PYTHONIOENCODING=utf-8` دوباره اجرا می‌شد).
- **پیشنهاد:** در `bootstrap.ps1` قبل از فراخوانی python‌ها `set PYTHONIOENCODING=utf-8` (و `$env:PYTHONIOENCODING`) یا خروجی‌ها ASCII.
- **مالکیت:** فایل‌ها در ریشه/`tools/` هستند و در جدول مالکیت مشخص نشده‌اند — برای سرپرست جهت تخصیص.

## نواقص نسبت به معیار (ویدیوها/فتاوی)

### GAP-1 — دروس
- محتوای درس فقط بلوک متنی (text/quote/callout/quiz_ref) است؛ صوت/ویدیو در درس نیست.
- «گروه‌های هم‌درسی» (cohorts) در CRM وجود دارد ولی وب هیچ مسیر ثبت‌نام/مشاهدهٔ گروه ندارد (داشبورد فقط «ثبت‌نام نکرده‌اید»).
- بدون آزمون مستقل در سطح دوره (فقط quiz درج‌شده در درس) و بدون گزارش نمره‌ها به‌جز میانگین داشبورد.
- تست روی گوشی واقعی انجام نشده (نیاز به موج سوم/فاز ۲).

### GAP-2 — کامیونیتی
- **ساخت گروه:** endpoint بک‌اند هست (`POST /social/groups`) ولی هیچ فرم/دکمه‌ای در وب نیست.
- **مدیریت گروه:** نه در وب نه در بک‌اند وجود دارد (فهرست اعضا، حذف عضو، ویرایش گروه، حذف گروه، مالک/ادمین). بک‌اند برای این‌ها نیاز دارد → تسک مشترک با ایجنت بک‌اند.
- **اعلان‌های اجتماعی:** endpointها هست (`/social/notifications` + `unread-count`) ولی UI در وب نیست.
- **ویرایش/حذف پست خودی:** endpoint در بک‌اند دیده نشد → نیاز به بررسی/تسک بک‌اند.

### GAP-3 — CRM
- در تب «درس‌ها» LMS، انتخاب دوره فقط یک `<select>` است (کار می‌کند ولی انتخاب از فهرست دوره‌ها در تب مجزا تجربهٔ ضعیف دارد) — جزئی.
- ویرایشگر زیرنویس فقط از لیست `/videos` باز می‌شود؛ در تب «بارگذاری/ویرایش» رسانه دسترسی مستقیم به زیرنویس آیتم دیده نشد (نیاز به راستی‌آزمایی با آیتم واقعی).
- خروجی‌های خالی (empty state) در همهٔ صفحه‌ها سالم و صادقانه بودند.
